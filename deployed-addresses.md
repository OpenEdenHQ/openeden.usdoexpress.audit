# USDO Deployed Addresses

Deployed contract addresses for the USDO / USDOExpress system. Proxy addresses (the stable, user-facing addresses) are listed; each links to its block explorer.

> USDO and cUSDO are cross-chain tokens (CCIP). A given address may recur across chains, and the same address can map to a different token role per chain (e.g. `0xaD55…aebc` is cUSDO on Ethereum but USDO on Base) — always match by chain **and** contract name, not by address alone.
